# Homebrewery User Guide - Technical Writing Sample

This repository contains a comprehensive, beginner-friendly user guide for **Homebrewery**, a web tool used to design book-style documents using Markdown.

## 🎯 Project Overview
This sample demonstrates my ability to take an application that relies on markup languages and translate its functionality into clear, structured, and empathetic documentation for end-users.

## 🚀 Skills Demonstrated
* **Docs-as-Code Methodology:** Managed entirely via Markdown and Git.
* **Complex Feature Simplification:** Explaining layout tools, formatting tags, and export workflows.
* **Information Architecture:** Clear heading hierarchy and logical user journey.
